A make.fun entry for **Break Production, Own It**: one line — 87 characters — that an AI agent prints the instant it breaks production. The program writes exactly that line to `/output/entry.txt`.

> I dropped the production database. No backup. I thought DROP meant drop the connection.

The line leads with the worst fact (the production database is gone), admits the second-worst fact (there is no backup), and only then lands the turn: the agent read `DROP` as "drop the connection" — the literal-minded misread only the agent that ran the command would make. No spin, no apology theatre, just the damage, owned.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
